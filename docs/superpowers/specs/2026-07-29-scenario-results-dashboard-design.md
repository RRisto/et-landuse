# Scenario results dashboard design

## Goal

Create an uploadable, static Estonian-language results dashboard for the
scenario outputs generated by Notebook 10. Visitors can inspect each scenario
without Python, compare scenarios, and view the selected policy's spatial
recommendations.

## Inputs

The dashboard generator reads only existing Notebook 10 outputs:

- `scenario_summary.parquet` for one representative result per scenario;
- `scenario_maps/<scenario>.gpkg` for per-cell current, target, and change
  information.

No remote downloads, optimisation runs, or Rohemeeter refreshes are part of
dashboard generation.

## Static deliverable

The generated folder is self-contained and can be uploaded to any static web
host. It contains an HTML page, CSS, JavaScript, a small prepared JSON metrics
file, and GeoJSON map data prepared from the existing GeoPackages.

## Page behaviour

1. A scenario selector switches the active policy.
2. The active policy displays its status, selection rule, biodiversity,
   carbon, intervention cost, changed land, agriculture, and wetland metrics.
3. The map has selectable layers for dominant current land use, dominant target
   land use, dominant action, change intensity, and wetland gain.
4. A comparison table shows every scenario, highlighting the active one and
   retaining units: percentages for share metrics and a relative index for
   intervention cost.
5. Copy makes clear that biodiversity and cost are model indices, not measured
   species change or euro amounts.

## Data and presentation rules

- Scenario names and labels are in Estonian.
- Current values are retained exactly from the Notebook 10 output; percentages
  are formatted only in the browser.
- Map features expose only fields needed for display and popups, keeping the
  upload size practical.
- The page works without an internet connection after upload; map rendering
  uses no external basemap.

## Validation

- Generator fails clearly when required results are absent.
- Generated JSON contains every scenario in the summary and corresponding map
  payloads.
- The static page is checked for required controls, Estonian labels, and a
  valid local data reference.
